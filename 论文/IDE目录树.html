HealthAI 后端项目目录结构树

IDE 视图下包含路由、服务、模型等核心类的层级结构
Explorer - health_analysis_system
📁 health_analysis_system/    // 项目根目录
├── 📁 frontend/               // Vue 前端源码目录 (含组件、视图等)
├── 📁 instance/               // Flask 实例配置与 SQLite 本地数据库文件
├── 📁 static/                 // 静态资源目录 (包含前端构建生成的 assets)
├── 📁 templates/              // HTML 模板目录 (包含前端打包后的 index.html)
├── 📁 utils/                  // 工具类/公共函数目录 (鉴权、加密、格式化等工具)
├── 📁 routes/                 // 路由与视图函数层 (API 控制器)
│   └── 🐍 __init__.py         
├── 📁 services/               // 核心业务服务层
│   ├── 🐍 ai_service.py       // 本地 AI 数据处理、健康评分推算与建议模型
│   ├── 🐍 cloud_ai_service.py // 云端大模型生态 (如深度解析与情绪报告) 对接逻辑
│   ├── 🐍 pdf_service.py      // 健康周报图文 PDF 生成引擎及排版服务
│   └── 🐍 services.py         // 基础核心业务逻辑处理入口
├── 🐍 app.py                  // Flask 应用核心入口、路由总线及跨域扩展配置
├── 🐍 models.py               // SQLAlchemy 数据库表模型及实体关系 ORM 定义
├── 🐍 simulator.py            // 智能传感器及体征监控设备的数据流模拟脚本
├── 📄 requirements.txt        // 生产环境与开发环境所需 Python 依赖包列表
└── 📄 .env                    // 本地关键系统环境变量与大模型 API Key 配置密钥
